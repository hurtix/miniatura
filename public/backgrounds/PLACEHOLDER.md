# 🖼️ Placeholders de Imágenes

Para que el generador funcione completamente, coloca las siguientes imágenes en este directorio:

## 📋 Imágenes Requeridas

```
backgrounds/
├── corporate-bg.jpg     # 📊 Imagen corporativa  
├── academic-bg.jpg      # 🎓 Imagen académica
├── modern-bg.jpg        # ✨ Imagen moderna
├── tech-bg.jpg          # 💻 Imagen tecnológica
├── nature-bg.jpg        # 🌿 Imagen de naturaleza
└── abstract-bg.jpg      # 🎨 Imagen abstracta
```

## 🎯 Mientras tanto...

Si no tienes las imágenes aún, la aplicación funcionará con:
- ✅ Vista previa mostrará fondo gris por defecto
- ✅ Los controles de opacidad funcionarán normalmente  
- ✅ El overlay de color se aplicará correctamente
- ⚠️ Las imágenes que no existan mostrarán el fallback
